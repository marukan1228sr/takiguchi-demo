# タキグチフルーツガーデン 公開デモ
WordPress不要の静的サイトです。index.htmlとassetsを含む、このフォルダの中身をGitHubリポジトリへアップロードしてください。

## GitHub Pagesで公開
1. GitHubで公開用リポジトリを作成します（無料プランの場合はPublic）。
2. このフォルダの中身をリポジトリ直下にアップロードし、コミットします。
3. Settings → Pages → Build and deploymentで「Deploy from a branch」を選びます。
4. Branchをmain、フォルダを/(root)にしてSave。
5. Pagesに表示される公開URLをクライアントへ共有します。

index.htmlだけでは写真が表示されないため、assetsとほかのHTMLも一緒にアップロードしてください。
右下の「モードを体験」で6種類のデザインに切り替えられます。パスワード不要で、選択は閲覧中のブラウザタブに保持されます。他の人の表示は変更されません。
管理者向けの編集・保存機能は含みません。注文・問い合わせ・決済・メール送信は動作しません。価格・送料・販売状況はサンプルです。
公開すると写真やページ文章はインターネットから閲覧できます。検索除外・アクセス制限は設定していません。
